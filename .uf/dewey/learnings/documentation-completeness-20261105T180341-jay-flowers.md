When a change extends an MCP tool's input schema, AGENTS.md's per-tool API reference sections are a documentation surface that proposal 'Docs:' impact lists tend to miss when they scope AGENTS.md updates to structural changes only. In dewey PR #156 (learning temporal validity), README's Temporal Validity section and the server.go tool description were updated, but AGENTS.md's 'Store Learning API' section still enumerated only the old inputs and automatic fields.
