In the dewey repo, AGENTS.md's strategic/tactical table says new MCP tools route to Speckit (Always) and never to OpenSpec, while the tier-routing skill's rubric only weighs user-story count and subsystem reach. A change that adds an MCP tool can therefore satisfy the skill and still contradict AGENTS.md. Reconcile the two governing documents (or record an explicit human authorization) before routing a new-tool change.
